## The image

A dense 1024×1024 data poster: 50 stories, all sourced. Lead stories — Nvidia reinstates Jensen Huang (+31%, biggest one-day jump since 2003), Tokyo reopens +3.8%, Abu Dhabi talks end with no deal, Russia warns Estonia, CAS rules on Senegal's AFCON title, Gaza strike, the Banten factory fire, the India–Nepal train, Puigdemont free to return home. Plus a UTC timeline, a schematic world map, four drawn information graphics, and a DATE CHECK box that states the true dates of the trickiest items (the Abu Dhabi round ended Mon 23 Nov; COP31 collapsed Sun 22 Nov).

`main.py` (Python 3.13, stdlib only) copies `entry.png` to `/output/entry.png` byte for byte — no network, no randomness, two runs identical.
